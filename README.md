# 🐠 Aquarien Manager

Eine Web-App zur Verwaltung deiner Aquarien.

## Funktionen
- Aquarien mit Literzahl verwalten
- Wasserwerte messen (pH, KH, GH, Nitrit, Nitrat, Ammoniak, Temperatur)
- Verlaufsgrafiken
- Fischbesatz dokumentieren
- Wasserwechsel-Termine planen
- Notizen für Zusätze
- Offline-fähig
- Installierbar als App

---

## 🚀 Anleitung: Auf GitHub Pages hosten

### Schritt 1: GitHub Account
Falls du noch keinen hast, erstelle einen kostenlosen Account auf [github.com](https://github.com)

### Schritt 2: Neues Repository erstellen
1. Klicke auf das **+** oben rechts → **New repository**
2. Name: `aquarium-manager` (oder was du willst)
3. Wähle **Public**
4. Klicke **Create repository**

### Schritt 3: Dateien hochladen
1. Klicke auf **uploading an existing file**
2. Ziehe alle 5 Dateien in das Feld:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
3. Klicke **Commit changes**

### Schritt 4: GitHub Pages aktivieren
1. Geh zu **Settings** (im Repository)
2. Links auf **Pages** klicken
3. Unter "Source" wähle **Deploy from a branch**
4. Branch: **main**, Ordner: **/ (root)**
5. Klicke **Save**

### Schritt 5: Fertig!
Nach 1-2 Minuten ist deine App online unter:
```
https://DEIN-USERNAME.github.io/aquarium-manager/
```

## 📱 Auf Android installieren

1. Öffne die URL in **Chrome**
2. Es erscheint ein Banner "App installieren" → tippe darauf
3. ODER: Tippe auf die **3 Punkte** (Menü) → **App installieren** oder **Zum Startbildschirm hinzufügen**

Die App erscheint dann als Icon auf deinem Homescreen! 🎉

---

## 💾 Backup & Restore

- **Backup**: Tippe oben rechts auf "💾 Backup" um deine Daten zu exportieren
- **Restore**: Die JSON-Datei einfach aufbewahren. Bei Datenverlust kannst du sie wieder importieren.
