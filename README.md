# Aquarium-Manager
Eine Web-App zur Verwaltung deiner Aquarien. Funktionen Aquarien mit Literzahl verwalten Wasserwerte messen (pH, KH, GH, Nitrit, Nitrat, Ammoniak, Temperatur) Verlaufsgrafiken Fischbesatz dokumentieren Wasserwechsel-Termine planen Notizen für Zusätze Offline-fähig Installierbar als App
